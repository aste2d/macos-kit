# Raycast 快捷键

在 General 中设置主快捷键 ⌘Space。在 Shortcuts 中按下表配置应用和命令；Downloads Manager 和 Kill Process 可从 Raycast Store 安装。

| 快捷键 | 功能 | 别名 |
|---|---|---|
| ⌥1 | 访达 |  |
| Hyper+P | 密码 | p |
| ⌥4 | 音乐 | m |
| Hyper+G | ChatGPT | c |
| ⌥2 | Discord |  |
| Hyper+T | Ghostty | t |
| ⌥3 | Google Chrome |  |
| Hyper+I | iPhone 镜像 | i |
| Hyper+V | Clipboard History |  |
| Hyper+D | Show Latest Download |  |
| Hyper+E | Search Emoji & Symbols | e |
| ⌘\ | Search Files | f |
| Hyper+K | Kill Process | kp |
| Hyper+B | Search Menu Bar Items |  |
| Hyper+A | Almost Maximize | a |
| Hyper+X | Maximize | x |
| Hyper+F | Toggle Fullscreen |  |
| Hyper+Enter | Toggle System Appearance |  |
